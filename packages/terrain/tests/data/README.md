The compressed arrays are decoded zoom-14 reference heights for the synthetic
AHN/GLO fixture in `test_integration.py`. They were produced with the original
uncommitted `../mapterhorn/pipelines/aggregation_reproject.py` and
`aggregation_merge.py` scripts at base commit
`7111a39e57bd76cbccd19cca37a07eb201e50bdf`, using GDAL 3.12.3 and the three
official PROJ grids, on 2026-10-22. Array names identify `z_x_y`. No real AHN or
Copernicus raster data is included. The processing provenance is recorded in
`../../MAPTERHORN_PROVENANCE.json`.
